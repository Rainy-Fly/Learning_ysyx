# Input & Output 元件
## Keyboard 键盘

**行为：** 读取键盘输入的 7 位 ASCII 字符，存入缓冲区。缓冲区最左字符的 ASCII 值从最右输出端输出；时钟触发时删除最左字符。支持可打印 ASCII 字符、空格、换行、退格、control-L、左右箭头移动光标、删除键删除光标右侧字符。缓冲区为空时输入字符会立即输出，无需等待时钟。

**引脚：**
- 西边（输入，1 位）：Clock——在 Read Enable 不为 0 时触发，删除最左字符并更新输出。
- 南边最左（输入，1 位）：Read Enable——为 1/悬空/错误时，时钟边沿消耗最左字符；为 0 时忽略时钟。
- 南边左起第二（输入，1 位）：Clear——为 1 时清空缓冲区，不再接受字符。
- 南边右起第二（输出，1 位）：Available——缓冲区至少有一个字符时为 1，为空时为 0。
- 南边最右（输出，7 位）：Data——最左字符的 7 位 ASCII 码，缓冲区为空时为 0。

**属性：**
- Buffer Length：缓冲区可容纳的字符数。
- Trigger：Rising Edge 时时钟 0→1 消耗最左字符；Falling Edge 时 1→0 消耗。

## ED Matrix ED 矩阵

**行为：** 显示小型像素网格，最多 32 行 × 32 列，像素值由输入决定。

**引脚：** 接口取决于 Input Format 属性：
- Columns：输入沿南边排列，每列一个多位输入，位数等于行数，低位对应最南端像素；1 点亮，0 暗淡；任一位悬空/错误则整列点亮。
- Rows：输入沿西边排列，每行一个多位输入，位数等于列数，低位对应最右端像素；任一位悬空/错误则整行点亮。
- Select Rows/Columns：西边两个输入，上方多位输入位数等于列数（低位对应最右列），下方多位输入位数等于行数（低位对应最底行）；对应列位和行位都为 1 时该像素点亮；任一位悬空/错误则全矩阵点亮。

**属性：**
- Input Format（创建后只读）：选择引脚与像素的对应方式。
- Matrix Columns：列数，1–32。
- Matrix Rows：行数，1–32。
- On Color：像素点亮时的颜色。
- Off Color：像素暗淡时的颜色。
- Light Persistence：不为 0 时，点亮的像素在输入指示应暗淡后仍保持点亮给定时钟滴答数。
- Dot Shape：square 为 10×10 方形无间隙；circle 为直径 8 圆形有间隙。

## Button 按钮

**行为：** 通常输出 0；用户用探测工具按下时输出 1。

**引脚：**
- 1 位输出：按下时为 1，否则为 0。

**属性：**
- Facing：输出引脚相对于组件的位置。
- Color：按钮显示颜色。
- Label：标签文本。
- Label Location：标签位置。
- Label Font：标签字体。
- Label Color：标签颜色。

---

## Joystick 操纵杆

**行为：** 用户可在圆角方形区域内拖动红色旋钮，输出更新为旋钮当前的 x、y 坐标，模拟经典街机操纵杆。

**引脚：**
- 西边上方（输出，位宽同 Bit Width）：x 坐标，无符号整数，永不为 0；1 为最左，最大值为最右；静止居中时位模式为 10...00。
- 西边下方（输出，位宽同 Bit Width）：y 坐标，取值范围同 x；顶部为 1，底部为最大值。

**属性：**
- Bit Width：每个坐标使用的位数。
- Color：旋钮颜色。

## 7-Segment Display 七段数码管显示

**行为：** 显示八个 1 位输入的值，段根据输入着色或呈浅灰色。

**引脚：**
- 北边左起第一（输入，1 位）：中间水平段。
- 北边左起第二（输入，1 位）：左侧上方垂直段。
- 北边左起第三（输入，1 位）：上方水平段。
- 北边左起第四（输入，1 位）：右侧上方垂直段。
- 南边左起第一（输入，1 位）：左侧下方垂直段。
- 南边左起第二（输入，1 位）：底部水平段。
- 南边左起第三（输入，1 位）：右侧下方垂直段。
- 南边左起第四（输入，1 位）：小数点。

**属性：**
- On Color：段和小数点点亮时的颜色（默认红色）。
- Off Color：段和小数点熄灭时的颜色（默认灰色）。
- Background：显示器背景颜色（默认透明）。
- Active On High?：yes 时输入 1 点亮；no 时输入 0 点亮。
- Has decimal point：yes 显示小数点，no 隐藏。
- Label：标签文本。
- Label Location：标签位置。
- Label Font：标签字体。
- Label visible：是否显示标签。

## Hex Digit Display 十六进制数字显示

**行为：** 用七段显示器显示四位输入对应的十六进制数字。输入非 0/1 时显示空白。单独 1 位输入控制小数点。

**引脚：**
- 南边左起第一（输入，4 位）：无符号四位数字，显示对应十六进制数字。
- 南边左起第二（输入，1 位）：控制小数点，未连接时小数点熄灭。

**属性：**
- On Color：段和小数点点亮时的颜色（默认红色）。
- Off Color：段和小数点熄灭时的颜色（默认灰色）。
- Background：显示器背景颜色（默认透明）。
- Has decimal point：yes 显示小数点，no 隐藏。
- Label：标签文本。
- Label Location：标签位置。
- Label Font：标签字体。
- Label visible：是否显示标签。

## TTY 终端

**行为：** 简单的哑终端，接收 ASCII 码并显示可打印字符。行满时换行，底行时向上滚动。支持退格（ASCII 8）、换行（ASCII 10）、换页（ASCII 12，control-L）清屏。

**引脚：**
- 西边上方（输入，7 位）：Data——下一个输入终端的字符 ASCII 值。
- 西边下方（输入，1 位，三角形标记）：Clock——在 Write Enable 不为 0 时触发，处理 Data 输入上的 ASCII 值。
- 南边最左（输入，1 位）：Write Enable——为 1/悬空/错误时，时钟边沿处理新字符；为 0 时忽略时钟和数据。
- 南边左起第二（输入，1 位）：Clear——为 1 时清空终端，忽略其他输入。

**属性：**
- Rows：终端显示行数。
- Columns：每行最大字符数。
- Trigger：Rising Edge 时时钟 0→1 处理数据；Falling Edge 时 1→0 处理。
- Color：终端文本颜色。
- Background：终端背景颜色。
